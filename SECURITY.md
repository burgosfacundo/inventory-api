# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please do not report it through a public GitHub issue.

Instead, use GitHub's **Private Vulnerability Reporting** feature available in the Security section of this repository.

Please include, when possible:

- A description of the vulnerability
- Steps to reproduce the issue
- The potential impact
- Any suggested mitigation or fix

Security reports will be reviewed as soon as possible.

## Supported Versions

This project is currently maintained as a portfolio and learning project. Security fixes are applied to the latest version available on the `main` branch.

## Security Features

This repository uses GitHub security features including:

- Secret Scanning and Push Protection
- Dependabot Alerts
- Dependabot Security Updates
- CodeQL Code Scanning
- Branch protection through GitHub Rulesets
